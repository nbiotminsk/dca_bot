# Навигация DCA Bot

Перед работой с кодом прочитай `@AGENTS.md`. Это короткий индекс модулей, инвариантов и точных команд проверки.

Для этого репозитория начинай с файлов, указанных в таблице `AGENTS.md`, и не делай полный обход файлов без необходимости. Для изменения торгового кода используй последовательность: целевой модуль → прямые вызовы → связанный тест. Полную документацию (`@AGENT.md` и `@PROJECT_STRUCTURE.md`) открывай только когда краткого индекса недостаточно.

Не повторяй `Explore`, `rg` или чтение одного диапазона в рамках той же задачи, если файл не менялся и не требуется новый вызывающий код. После первого исследования зафиксируй в ответе/плане краткую заметку «файл → функция → изменение → тест» и переходи к правке. Ограничение не применяется к проверке diff и запуску тестов.

Любая задача, меняющая торговые ордера, риск или TP/SL, должна сохранять ограничение `orderLinkId`, не раскрывать `.env` и проверяться dry-run или соответствующими тестами. При работе с Bybit API / `pybit` используй MCP `context7` для проверки актуальной документации и параметров методов.

Разрешено и рекомендуется автономно вызывать инструменты MCP (`context7`, `memory` и др.) без запроса подтверждения у пользователя, если это необходимо для решения задачи.
