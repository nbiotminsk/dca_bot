# DCA Bot — Bybit V5 Algorithmic Trading System & Fibonacci Grid

Профессиональная алгоритмическая система для торговли бессрочными фьючерсами Bybit (**Linear USDT Perpetuals**) по стратегии **«Манипуляция на часе» (1H Fibonacci Price Action & Dual Grid)**.

Система включает в себя:
* 🤖 **Боевой торговый бот Bybit V5** (`scripts/bybit_trader.py`) с поддержкой мульти-монетной торговли, динамического трейлинга уровней, автоматического безубытка и защиты от дублирования ордеров.
* 📈 **Индикатор TradingView** (`indicators/fib_dual_grid.pine`) — синхронизированная Pine Script v5 версия с визуализацией импульсов, сеток и сигналов ложного пробоя.
* 🧪 **Интерактивный бэктестер** (`scripts/backtest_strategy_interactive.py`) с Rich-интерфейсом и эмуляцией рыночного исполнения.
* 📊 **Модули волатильности и оптимизации DCA** (`volatility_calc/`).
* 🛡️ **Комплекс тестов** (`tests/test_bybit_trader.py`, 157 unit-тестов).

## 1. Три варианта торговой стратегии (1H Timeframe)

Все варианты базируются на логарифмической сетке Фибоначчи от часового импульса ($H$ — абсолютный максимум волны, $L$ — старт импульса):

$$\text{Price}(\text{level}) = \exp\Big(\ln(H) - \text{level} \times \big(\ln(H) - \ln(L)\big)\Big)$$

### 🔹 Вариант 1: Ложный пробой (Sweep Reclaim + MACD + Безубыток)
* **Условия:** Закол уровня `1.000 Fib` не более чем на **0.5%** без закрепления (ни одна свеча не закрывается телом ниже 1.000) + подтверждение отскока гистограммы MACD.
* **Вход:** На возврате цены выше уровня `1.000` (Reclaim).
* **Стоп-Лосс:** За минимум тени свипа (`SweepLow * 0.9995`).
* **Тейк-Профит:** Уровень **0.618 Fib МИНУС 2.0%**.
* **Безубыток:** При росте цены до уровня **0.786 Fib** стоп-лосс автоматически переносится в безубыток (`Вход + 0.05%`).

### 🔹 Вариант 2: Тройная сетка коррекции (Triple Grid) с Трейлингом и каскадным Тейк-Профитом
* **Ордер 1:** Уровень **0.500 Fib** $+0.07\%$ буфер входа. Тейк: **0.236 Fib** $-0.10\%$ буфер. При закрытии по TP ордера 2 и 3 отменяются.
* **Ордер 2:** Уровень **0.618 Fib** $+0.07\%$ буфер входа. При наливе цель всей позиции снижается до **0.382 Fib** $-0.10\%$ буфер. Ордер 3 остается в стакане. При закрытии по TP Ордер 3 снимается.
* **Ордер 3:** Уровень **0.786 Fib** $+0.07\%$ буфер входа. При глубоком проливе до 0.786 цель для ВСЕХ трех ордеров снижается до **0.500 Fib** $-0.10\%$ буфер! Ордер 3 дает сверхприбыль, Ордер 2 закрывается в плюс, Ордер 1 выходит в безубыток.
* **Стоп-Лосс:** Уровень **1.000 Fib**. Объем позиции распределяется в пропорции **50% / 30% / 20%** (0.500 / 0.618 / 0.786), а совокупный риск при выбивании SL равен $2.00.
* **Трейлинг:** При обновлении максимума импульса без коррекции к 0.500 все три ордера динамически подтягиваются вверх вслед за рынком.
* **Защита от зависания:** При срабатывании SL или закрытии позиции незаполненные лимитные ордера немедленно снимаются.

### 🔹 Вариант 3: Сетка манипуляции (Deep Manipulation Grid 1.414 & 1.618 — 100% Win Rate)
* **Условия:** Пробой $1.000$ глубже **0.5%** или закрытие часовой свечи телом ниже 1.000 (когда нет отскока с дивергенцией MACD).
* **Ордер 1:** Уровень **1.414 Fib** $+0.10\%$ буфер $\to$ одиночный Тейк-Профит на **1.000 Fib** $-0.10\%$.
* **Ордер 2 (DCA):** Уровень **1.618 Fib** $+0.10\%$ буфер $\to$ при наливе Ордера 2 общий Тейк-Профит корзины переносится на **1.414 Fib** $-0.10\%$ (Ордер 1 в безубыток, Ордер 2 в прибыль).
* **Стоп-Лосс:** Уровень **2.414 Fib** (суммарный риск распределяется по \$2 на ордер).
* **Винрейт:** **100%** (16 TP из 16 дампов на SUI и NEAR).

## 2. Двухуровневая торговая система (Dual-Layer Fibonacci Architecture)

На каждой монете бот параллельно и независимо ведет два слоя торговли:

| Слой | Длительность импульса | Риск на сделку | Префикс ордеров | Поведение до отката к 0.382 |
| :--- | :--- | :--- | :--- | :--- |
| **Minor (Мелкая фиба)** | $\le 24$ свечей | $2.00 | `FIB-{SYM}-MIN-B-O1..3` | Выставляется сразу при обнаружении импульса |
| **Major (Большая фиба)** | $25..96$ свечей | $2.00 | `FIB-{SYM}-MAJ-B-O1..3` | **Экономия маржи!** Лимитки не выставляются до касания 0.382 |

### 🛡️ Экономия маржи старшей фибы (`AWAITING_MAJOR_0382`):
* Если на монете обнаружен крупный импульс ($25..96$ свечей), но текущая цена находится выше уровня $0.382$ — **лимитные ордера на биржу НЕ выставляются**, чтобы не морозить депозит.
* Монитор переходит в состояние `AWAITING_MAJOR_0382`, динамически трейлит вершину и пересчитывает уровень $0.382$.
* Как только цена касается или пробивает $0.382$ ($low \le p_{0.382}$), сетка Большой фибы мгновенно активируется и выставляется на Bybit (`TRAILING`).
* **Полная изоляция отмены ордеров:** Отмена ордеров строго привязана к слою (`cancel_monitor_orders`). Закрытие локальной сетки Minor по TP или SL не отменяет лимитки старшей сетки Major, и наоборот.

## 3. Установка и настройка окружения

Проект использует современный быстрый менеджер пакетов **`uv`** (Python 3.11+):

```bash
# Клонирование репозитория
git clone https://github.com/nbiotminsk/dca_bot.git
cd dca_bot

# Установка зависимостей через uv
uv sync
```

### Настройка API-ключей Bybit (`.env`)
Создайте в корне проекта файл `.env`:
```env
BYBIT_API_KEY="ваш_api_key"
BYBIT_API_SECRET="ваш_api_secret"
BYBIT_TESTNET="false"   # true для тестовой сети, false для Mainnet
```

## 4. Конфигурация (`config/trade_config.yaml`)

Файл параметров стратегии и риск-менеджмента:

```yaml

  major_risk_usd: 2.0          # Риск на сделку большой фибы ($2.00)
  manipulation_risk_usd: 2.0   # Риск на каждый ордер манипуляции ($2.00)

buffers:
  entry_buffer_pct: 0.10       # Буфер входа перед Фибой (+0.10%)
  tp_buffer_pct: 0.10          # Буфер тейка перед Фибой (-0.10%)

  reclaim_be_trigger_fib: 0.786 # Триггер безубытка: 0.786 Fib

  min_impulse_pct: 2.0         # Минимальный размер импульса (2.0%)

  minor_max_impulse_bars: 24   # Макс. длительность мелкого импульса (свечей)
  major_max_impulse_bars: 96   # Макс. длительность крупного импульса (свечей)
  timeframe: "1h"              # Рабочий таймфрейм
  scale: "log"                 # Логарифмическая шкала Fib
  symbols:                     # Список монет для сканирования и торговли
    - "NEARUSDT.P"
    - "ZECUSDT.P"
    - "ICPUSDT.P"
    - "CAKEUSDT.P"
    - "STRKUSDT.P"
    - "SUIUSDT.P"
    - "BNBUSDT.P"
```

## 5. Запуск торгового бота (`bybit_trader.py`)

### 5.1. Режим симуляции (Dry-Run / Сканер)
Сканирует рынок по всем монетам из конфига по обоим слоям (Minor и Major), рассчитывает параметры ордеров и выводит таблицы:
```bash
uv run python scripts/bybit_trader.py --dry-run
```

Выборочный запуск для определенных монет:
```bash
uv run python scripts/bybit_trader.py --symbols "NEAR,ZEC,SUI" --dry-run
```

### 5.2. Боевой режим (Live Trading)
Запуск параллельной торговли на реальном аккаунте Bybit с автоматическим выставлением ордеров и переходом в непрерывный мониторинг:
```bash
# Непрерывный фоновый цикл (сопровождение сделок + автопоиск новых импульсов на закрытиях свечей)
uv run python scripts/bybit_trader.py --live -y

# Одиночный проход мониторинга без повторного сканирования
uv run python scripts/bybit_trader.py --live -y --once
```

### 5.3. Особенности боевого режима и конечный автомат (State Machine):
* **Полный жизненный цикл сделки:**
  1. `AWAITING_MAJOR_0382`: для Большой фибы ($25..96$ баров) при цене выше 0.382 — маржа свободна, бот трейлит вершину. При $low \le p_{0.382}$ выставляется сетка `MAJ` и монитор переходит в `TRAILING`.
  2. `TRAILING`: выставляются три лимитных ордера (0.500, 0.618, 0.786); при росте цены уровни подтягиваются вверх за вершиной.
  3. `O1_FILLED`: при наливе Ордера 1 тейк позиции стоит на 0.236 Fib. При развороте цены в плюс (TP 0.236) бот фиксирует прибыль и немедленно снимает висящие Ордера 2 и 3 своего слоя.
  4. `O2_FILLED`: при проливе до 0.618 наливается Ордер 2 — бот мгновенно переносит Take-Profit позиции на общий уровень **0.382 Fib** через Bybit API. Ордер 3 остается в стакане. При взятии TP 0.382 Ордер 3 снимается.
  5. `O3_FILLED`: при глубоком сквизе до 0.786 наливается Ордер 3 — бот переносит Take-Profit всей совокупной позиции на общий уровень **0.500 Fib (-0.10%)**. Ордер 3 закрывается в сверхприбыль, Ордер 2 в плюс, Ордер 1 в безубыток!
  6. `AWAITING_SWEEP_CLOSE`: при срабатывании стопа на 1.000 бот снимает ордера своего слоя и дожидается закрытия часовой свечи:
     - Свеча закрылась **выше 1.000** (`close >= 1.000`), закол $\le 0.5\%$ + разворот MACD $\to$ вход в **Вариант 1 (Sweep Reclaim)**.
     - Свеча закрылась **ниже 1.000** (`close < 1.000`) или закол $> 0.5\% \to$ переход в **Вариант 3 (Сетка манипуляции 1.414 / 1.618)** со стопом на 2.414.
  7. `IDLE`: сделка завершена; на закрытиях последующих свечей бот автоматически сканирует монеты на появление новых импульсов соответствующего слоя.
* **Контроль остаточного риска (Residual Risk Budget):** Если позиция уже набрана, бот пересчитывает задействованный риск и калибрует доборы строго из остатка лимита $2.00. Если лимит риска исчерпан — любые новые ордера блокируются.
* **Защита от дублирования через `orderLinkId`:** Биржевые идентификаторы ордеров гарантируют, что Bybit отклонит любые дубликаты при сбоях сети или параллельных запусках.
* **Режим Close-Only:** Позиции по монетам вне активного списка торговли сопровождаются строго до закрытия без открытия новых сеток.
* **Поддержка Bybit Hedge Mode:** Автоматическое определение режима позиций аккаунта (Hedge Mode `positionIdx: 1/2` vs One-Way Mode `positionIdx: 0`).
* **Трейлинг без лишних запросов:** Бот проверяет изменение цены на биржевой шаг (`tick_size`) перед отправкой `amend_order`, предотвращая ошибку Bybit `10001 (order not modified)`.

## 7. Тестирование (Unit Tests)

Набор из **173 автоматических тестов** покрывает:
* Форматирование тикеров (включая TV-суффиксы `.P` и `.PERP`).
* Округление шага цены и лота по биржевым спецификациям.
* Детекторы импульсов, тройной сетки трейлинга, ложного пробоя и манипуляции.
* Двухуровневую торговлю: независимые фильтры Minor ($\le 24$ свечей) и Major ($25..96$ свечей).
* Экономию маржи старшей фибы: переход в `AWAITING_MAJOR_0382` при цене выше 0.382 и активацию сетки при пробое 0.382.
* Послойную изоляцию отмены ордеров (`cancel_monitor_orders`).
* Раздельный риск-менеджмент: \$2.00 на Minor, \$2.00 на Major и самостоятельные \$2.00 на каждый ордер манипуляции (1.414 и 1.618).
* Равновесный расчет риска 1/3, 1/3, 1/3 для тройной сетки.
* Расчет остаточного риска (Residual Risk) и защиту от дублирования `orderLinkId`.
* Все переходы состояний State Machine (добор 0.618 $\to$ TP 0.382, добор 0.786 $\to$ TP 0.500, перенос корзины манипуляции в TP 1.414, снятие ордеров, анализ закрытия свечи свипа).
* Валидацию списка монет и отсутствие хардкодных дефолтов.

Запуск тестов:
```bash
uv run pytest -v
```
