# Шаблон тестирования монет: Стратегия «Манипуляция на часе» (Fibonacci Grid)

Данный документ является эталонным регламентом и примером тестирования криптовалютных пар на бирже Bybit (или других биржах) по авторской стратегии импульсов Фибоначчи и Манипуляций.

---

## 1. Типовой запрос для запуска тестирования новой монеты

> *"Сделай тест на 90 дней монеты [ТИКЕР], график часовой (1h). Проверь отдельно только лонг, потом только шорт сделки. Проверь стопы на 0.86 и 1.0 уровнях. Проверь тейки 0.5 к 0.382 и к 0.236. Тейки 0.618 к 0.382. И 0.786 к 0.5. Проверь как часто есть вход к 1.414, 1.618, 2.0 и как часто срабатывает стоп 2.4 или 2.6, как часто сработает тейк к 0.618 и к 0.5 от 1.414, 1.618, 2.0. Далее проверь все индикаторы по очереди, а потом найди индикаторы, которые в паре увеличивают винрейт, с оценкой сокращения количества сделок."*

---

## 2. Архитектура и методология тестирования

Все расчеты проводятся строго по **логарифмической шкале (Log Fib)**, как в `index.php`:
$$\text{Long Level}(L) = \exp\big(\ln(H) - L \times (\ln(H) - \ln(L_s))\big)$$
$$\text{Short Level}(L) = \exp\big(\ln(L_s) + L \times (\ln(H) - \ln(L_s))\big)$$

### Этап 1: Базовая сетка импульсов (Long vs Short)
Сравнение направлений рынка на 90 днях с минимальным импульсом $\ge 1.5\%$:
- **Стопы:**
  - `0.860 Fib` — быстрый технический стоп (выше базы);
  - `1.000 Fib` — стоп на базу (минимум/максимум импульса). Защищает от ложных заколов 0.860.
- **Связки Вход → Тейк:**
  1. `0.500` → `0.382` (Высокая частота исполнения, быстрый скальпинг)
  2. `0.500` → `0.236` (Широкий тейк, максимизация PnL при сильном тренде)
  3. `0.618` → `0.382` (Классический золотой вход с высоким Profit Factor)
  4. `0.786` → `0.500` (Глубокий откат с коротким стопом)

### Этап 2: Зона Манипуляции (уровни расширения ниже 1.000)
Проверка поведения цены при выносе базы (стоп-хантинг крупным игроком):
- **Точки входа:** `1.414`, `1.618`, `2.000` Fib
- **Стоп-лоссы манипуляции:** `2.400` и `2.600` Fib (критический рубеж смены тренда)
- **Тейк-профиты манипуляции:** возврат к `0.618` и `0.500` Fib

### Этап 3: Одиночные индикаторы-фильтры (Single Filters)
Оценка фильтрации входов по 9 популярным индикаторам:
1. `RSI(14)`: `< 35` / `< 40`
2. `CCI(14)`: «Золотой вход» `[-100, 0]` из `index.php`
3. `EMA 200 / EMA 50`: фильтр глобального тренда (`Close > EMA`)
4. `MACD(12, 26, 9)`: моментум покупателя (`Histogram > 0`)
5. `Stochastic RSI(14, 14, 3, 3)`: зона перепроданности (`< 20`)
6. `Bollinger Bands(20, 2.0)`: касание нижней полосы (`touch_lower`)
7. `SuperTrend(10, 3.0)`: подтверждение бычьего направления тренда
8. `ATR(14)`: фильтр повышенной волатильности (`ATR > SMA(20)`)
9. `Volume(20)`: фильтр всплеска торговой активности (`Volume > SMA(20)` или `> 1.5x`)

### Этап 4: Синергия парных индикаторов (Dual Filters)
Поиск комбинаций, увеличивающих Win Rate при минимальном срезании прибыльных сделок:
- Тренд + Осциллятор: `SuperTrend + CCI (Golden)`, `EMA 200 + RSI`
- Тренд + Объем: `SuperTrend + Volume (> SMA)`
- Моментум + Объем: `MACD + Volume (> SMA)`
- Волатильность + Осциллятор: `Bollinger + CCI (Golden)`

## 3. Готовые CLI-команды для тестирования любой монеты

### Полный автоматический матричный прогон по всем 4 блокам:
```bash
python3 scripts/run_comprehensive_matrix.py
```
*(Чтобы протестировать другую монету, передайте тикер: `run_test_suite("SOLUSDT", days=90)`)*.

### Быстрые команды бэктестера для проверки конкретных сетапов:

1. **Базовый Long со стопом 1.000 (высокая частота, WR > 70%):**
```bash
python3 scripts/backtest_strategy_interactive.py [МОНЕТА] -tf 1h -d 90 --side long --entry 0.500 --tp 0.382 --sl 1.000
```

2. **Максимизация прибыли (Long 0.500 к 0.236 с высоким PnL):**
```bash
python3 scripts/backtest_strategy_interactive.py [МОНЕТА] -tf 1h -d 90 --side long --entry 0.500 --tp 0.236 --sl 0.860
```

3. **Классический вход 0.618 со стопом 0.860 (максимальный Profit Factor):**
```bash
python3 scripts/backtest_strategy_interactive.py [МОНЕТА] -tf 1h -d 90 --side long --entry 0.618 --tp 0.382 --sl 0.860
```

4. **Тест Манипуляции (вход 1.414 или 1.618 с тейком на 0.500):**
```bash
python3 scripts/backtest_strategy_interactive.py [МОНЕТА] -tf 1h -d 90 --side long --entry 1.414 --tp 0.500 --sl 2.400
```

5. **Тест с топовыми фильтрами (SuperTrend / MACD + Volume):**
```bash
python3 scripts/backtest_strategy_interactive.py [МОНЕТА] -tf 1h -d 90 --side long --entry 0.500 --tp 0.382 --sl 1.000 --supertrend trend --vol "> sma"
```

## 5. Исследование размаха импульсов (Корзины от 1.0% до 5.0% с шагом 0.5%)

- **< 2.0% (Микро-импульсы):** Имеют отрицательное математическое ожидание из-за комиссий и ложных пробоев.
- **2.5% — 3.5% (Скальп-зона):** Винрейт достигает **88% – 90%**, идеальная зона для быстрого скальпинга.
- **>= 5.0% (Трендовая зона):** Дает максимальную прибыль (**+43.42%** на широком тейке 0.236 при винрейте **80.0%**).
