# 🗺️ Структура проекта DCA Bot (Fibonacci Dual Grid & Bybit Bot)

Данный документ описывает полную архитектуру репозитория, назначение каждой директории и файла, а также служит навигационным путеводителем для разработчиков и трейдеров.

---

## 📁 Дерево проекта

```text
dca_bot/
├── config/                  # Конфигурационные файлы (YAML) стратегий и подключения к Bybit
├── data/                    # Кэш исторических свечей и журнал сделок
├── docs/                    # Документация, исследования, аналитика монет и стратегий
│   ├── coins/               # Анализ и результаты бэктестов по конкретным монетам
│   ├── plans/               # Архитектурные планы и дорожные карты
│   └── strategies/          # Руководства, спецификации и книги по стратегиям
├── indicators/              # Математика индикаторов (Python) и скрипты TradingView (Pine Script)
├── results/                 # Результаты прогонов бэктестов (JSON-отчеты)
├── scripts/                 # Исполняемые скрипты: торговый бот, бэктестеры, исследования
├── tests/                   # Набор автотестов (pytest)
├── trade_tracker/           # Подсистема учета и аналитики сделок
├── volatility_calc/         # Модуль расчета волатильности, ликвидаций и оптимизации сеток
├── web/                     # Веб-инструменты: PHP-скринеры, калькуляторы и HTML-интерфейсы
├── .env.example             # Пример файла переменных окружения (ключи Bybit API)
├── AGENT.md                 # Техническая база знаний и инструкции для ИИ-агентов
├── PROJECT_STRUCTURE.md     # Этот файл: полное описание архитектуры и навигации
├── README.md                # Главная вводная документация проекта
├── pyproject.toml           # Метаданные Python-проекта и зависимости (uv / pip)
├── requirements.txt         # Список зависимостей
├── run.bat                  # Меню управления под Windows (Batch)
├── run.ps1                  # Меню управления под Windows (PowerShell)
└── uv.lock                  # Зафиксированные версии пакетов uv
```

## 🧭 Подробное описание компонентов

### 1. 🚀 Исполняемые скрипты и бот (`scripts/`)

Центральное место запуска алгоритмов и исследований.

| Файл | Назначение |
| :--- | :--- |
| **`bybit_trader.py`** | **Основной торговый бот Bybit V5.** Поддерживает режимы `--live` (реальная торговля) и Dry-Run (безопасный мониторинг без ордеров). Мульти-монетная торговля, подхват ордеров по `orderLinkId`, автоматический трейлинг сеток, контроль риска (`Residual Risk Budget`). |
| **`backtest_strategy_interactive.py`** | **Интерактивный бэктестер.** Позволяет тестировать стратегию «Манипуляция на часе» / Фибоначчи сетки с выбором монеты, периода, фильтров (EMA, RSI, CCI) и шкал (Log/Linear). |
| **`strategy_engine.py`** | Ядро симуляции исполнения сеток ордеров (Minor/Major, усреднения, тейки, стопы, учет комиссий мейкер/тейкер). |
| **`pyalgotrade_engine.py`** | Адаптер интеграции стратегии с фреймворком PyAlgoTrade. |
| **`constants.py`** | Общесистемные торговые константы (комиссии биржи Bybit, таймауты свечей, списки топ-монет). |
| **`backtest_filters_research.py`** | Исследование влияния ATR-фильтра волатильности и времени удержания (Staleness Timeout). |
| **`research_wick_vs_body.py`** | Исследование пробоя 2-й свечи импульса: сравнение входов по телу свечи vs по фитилю (Wick). |
| **`research_fib_comprehensive.py`** | Комплексный перебор параметров уровней Фибоначчи и соотношений риск/прибыль. |
| **`compare_strategies_12_coins.py`** | Сравнительный анализ эффективности стратегий на пуле из 12 ликвидных альткоинов за 90 дней. |
| **`run_dual_grid.py`** | Запуск бэктеста параллельных сеток (Dual Grid: Minor + Major). |
| **`run_top30_backtest.py`** | Массовый стресс-тест стратегии на топ-30 монетах Bybit за 6 месяцев. |
| **`add_trade.py`** / **`import_trades.py`** | Утилиты ручного добавления или импорта сделок в журнал трекера. |
| **`trade_report.py`** | Генерация текстового/консольного отчета по эффективности закрытых позиций. |
| **`test_bybit_connection.py`** | Скрипт быстрой проверки валидности API ключей Bybit и пинга к бирже. |

### 2. 📐 Индикаторы и биржевой клиент (`indicators/`)

Модуль расчета математических индикаторов и прямой работы с API биржи.

| Файл | Назначение |
| :--- | :--- |
| **`pybit_client.py`** | **Обертка над Bybit API V5 Linear.** Авто-определение режима позиции (One-Way / Hedge Mode `positionIdx`), нормализация шага цены и лота (`tick_size`, `qty_step`), расчет объемов, размещение, сдвиг (`amend_order`) и отмена ордеров, защита от сброса соединения (`force_retry`). |
| **`fib_dual_grid.pine`** | **Pine Script v5 индикатор для TradingView.** Полная визуальная копия логики бота: отрисовка импульсов, уровней сетки Фибоначчи, детекция ложного пробоя (Sweep Reclaim), встроенный фильтр MACD и риск-калькулятор. |
| **`dca_grid.pine`** | Базовый скрипт визуализации классической DCA-сетки в TradingView. |
| **`filter_manager.py`** | Менеджер комбинирования сигналов и фильтров (EMA Cross, RSI фильтр, CCI «Золотой вход»). |
| **`base.py`** | Базовый интерфейс для расчетных индикаторов. |
| `atr.py`, `cci.py`, `rsi.py`, `macd.py`, `ema.py`, `bollinger.py`, `supertrend.py`, `volume.py` | Чистые реализации расчетных индикаторов на Python (с формулами, откалиброванными под TradingView и Bybit). |

### 3. ⚙️ Конфигурации (`config/`)

Все настройки торгового бота и пресеты параметров под различные активы.

| Файл | Описание |
| :--- | :--- |
| **`trade_config.yaml`** | **Основной конфиг боевого бота.** Список торгуемых пар, риск на сделку, пропорции сетки (Minor/Major), параметры фильтров и режим работы (Live/Dry-run). |
| `settings.yaml` | Базовые глобальные настройки. |
| `settings_eth.yaml` | Оптимизированный пресет сетки под Ethereum (ETHUSDT). |
| `settings_hype*.yaml` | Серия откалиброванных конфигураций под монету Hyperliquid (HYPEUSDT): `fast`, `calibrated`, `deep_dca`, `safe`, `10ord`. |

### 4. 🌐 Веб-скринеры и калькуляторы (`web/`)

Автономные веб-инструменты, работающие на любом PHP-сервере или локально в браузере:

| Файл | Описание |
| :--- | :--- |
| **`web/index.php`** | **Интерактивный Web Screener & Signal Scanner.** Сканирует стакан и свечи Bybit в реальном времени, находит сигналы на 1H таймфрейме, вычисляет логарифмические уровни Фибоначчи и отображает риск-калькулятор входа. |
| **`web/calculator.php`** | Мульти-монетный бэкенд и UI калькулятора мартингейла/DCA для фьючерсов с загрузкой истории котировок с Bybit. |
| **`web/scan_signals.php`** | Скрипт быстрого сканирования рынка на наличие сформированных импульсов. |
| **`web/test.php`** | Автономный веб-бэктестер DCA-стратегий на PHP. |
| **`web/futures_grid_calculator.html`** | Standalone HTML/JS калькулятор параметров фьючерсной сетки ордеров (расчет ликвидации, средней цены, профита). |
| **`web/martingale_calculator.html`** | Визуальный HTML/JS калькулятор шага мартингейла и распределения депозита. |

### 5. 🛡️ Управление волатильностью и рисками (`volatility_calc/`)

Комплексный анализ рыночной ситуации и предотвращение ликвидаций.

- **`data_fetcher.py`** — загрузка исторических данных и стакана с Bybit в кэш (`data/cache`).
- **`regime.py`** — определение режима рынка (флэт, тренд, всплеск волатильности).
- **`liquidation.py`** — прецизионный расчет цен ликвидации с учетом плеча и комиссий.
- **`dca_recommender.py`** — рекомендации по плотности и глубине шага сетки ордеров.
- **`drawdown_analyzer.py`** — расчет максимальной просадки (Max Drawdown) и продолжительности просадок.
- **`optimizer.py`** / **`portfolio_optimizer.py`** — подбор оптимальных весов и параметров DCA для портфеля монет.
- **`backtest.py`** — движок исторической симуляции рисков.

---

### 6. 📊 Учет и журнал сделок (`trade_tracker/`)

Хранение, обогащение и анализ торговой статистики.

- **`models.py`** — дата-классы сделок, позиций, ордеров (`Trade`, `Position`, `TradeStatus`).
- **`storage.py`** — сохранение истории сделок в JSON/CSV (`data/trades/`).
- **`calculator.py`** — расчет чистого PnL, доходности в %, винрейта, комиссий биржи.
- **`comparator.py`** — сравнение теоретических бэктестов с реальными сделками на бирже.
- **`aggregator.py`** & **`report.py`** — агрегированная статистика и форматирование сводных отчетов.

## ⚡ Шпаргалка: «Что запускать?»

| Задача | Команда |
| :--- | :--- |
| **Запустить интерактивную панель управления** (Windows) | Запустить `run.bat` или `run.ps1` |
| **Запустить бота в безопасном режиме (Dry-Run)** | `uv run python scripts/bybit_trader.py` |
| **Запустить бота в БОЕВОМ режиме (Live Bybit)** | `uv run python scripts/bybit_trader.py --live` |
| **Интерактивный бэктестер стратегии** | `uv run python scripts/backtest_strategy_interactive.py` |
| **Проверить подключение к Bybit** | `uv run python scripts/test_bybit_connection.py` |
| **Запустить все автотесты** | `uv run pytest` |
| **Открыть локальный веб-скринер** | `php -S localhost:8000 -t web/` (открыть в браузере `http://localhost:8000`) |
